### Research file v1.0 · status as of 30 October 2026 (re-check every row at build)

**Why this file exists.** Lists of "people around Epstein who died" circulate widely: the National Enquirer's 22 names (August 2025), the Epstein subreddit's dozen, and videos like the ones Ron supplied. The public is asking. The book answers case by case. Each death gets:
- the official finding, first;
- every documented anomaly or dissent;
- every documented failure by the institution responsible;
- what is still open, with a date to re-check.

A pattern is claimed only where the documents show one.

## B. The pattern pass

### 1. Is there a documented killing pattern?
**No.** Every death with a finished official process was ruled suicide, natural, accidental or medical. The one exception is Shapiro (1985): an unsolved homicide, with a link to Epstein running only through Wexner. Two processes are still open (Giuffre's coroner and Andriesz's cause of death), and one dissent is scheduled (Freeman, 16 Nov). The book says so in the same plain voice it uses for what *is* documented. It does not "keep the question alive" by implication.

### 2. Is there a documented pattern at all?
**Yes, and it is a different one.** Across at least seven cases, the documents show two things:
1. **testimony was lost before it was taken;**
2. **the institution responsible for the person, the evidence or the follow-up failed in a documented way.**

| Case | Testimony lost | Documented institutional failure |
|---|---|---|
| Epstein | No trial; no cooperation | MCC: watch, cellmate, rounds, records, cameras. FBI: destroyed master video. |
| Brunel | No trial | Should have been treated as a high suicide risk (expert report) |
| Siad | Never questioned | Not heard in more than 4 months despite asking |
| Andriesz | Tips not pursued; died before any follow-up | FBI "no interest"; FCA now reviewing its own handling |
| Giuffre | No inquest yet | WA police reviewing their own response |
| Hoffenberg | 2010 interview conditional on counsel; no follow-up found | (to verify) |
| Shapiro | Died the day before the grand jury | Police report destroyed by order of the chief |

This passes the two-precedents bar comfortably. **The mechanism, named without naming an actor: evidence decays faster than institutions act.** People die, of whatever cause, before their testimony is taken. Records are destroyed as "no longer pertinent". Custody rules are broken around the one prisoner who most needed them followed. Tips are logged and never opened.

This is the book's honest version of "power protects power". It needs no assassin, and it is fully documented. **It is also the version no official can wave away as a conspiracy theory.**

### 4. Code panel: a weak reference
```objc
@property (nonatomic, weak) Witness *witness;   // nobody holds a strong reference
// ...years pass; the object is released...
[self.witness testify];   // message to nil: no crash, no error, no testimony
```
In plain language: in Objective-C, sending a message to an object that is already gone (nil) fails silently. Nothing crashes and nothing is returned. Nobody in the system held on to these witnesses, whether that meant safe custody, prompt questioning or a preserved recording. When the question was finally asked, the answer was silence, and the system logged no error.
