This appendix shows the architecture of the road to 1948 in two other languages: code and diagrams. The code is Objective-C, the language Apple's software was written in for three decades, whose runtime lets a program change its own behaviour while it runs. Its techniques have names for things institutions do: run before anyone can object, keep a label while changing what it does, speak through an intermediary, route everything through one gateway, extend a scope without ever redrawing it.

Nothing here is new evidence. Every fact in the code comes from the stages of this volume, with its source, and every block of code is followed by the same thing in plain language. The code is a way of seeing the structure; the record is the evidence. The appendix ends with two diagrams, the institutions and their documented ties, and the whole system on one page, and with a list of what the code does not claim.
