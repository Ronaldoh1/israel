Part Twelve asks whether Epstein was an aberration. The question matters, because the answer decides what kind of problem the reader is looking at: a single criminal who exploited a few loopholes, or a structure that keeps producing the same outcome wherever the same conditions meet.

The method is the one used throughout this book. It names the mechanism, not the people. It counts a pattern only where at least two other documented cases show the same thing. It names who broke each case open. And it keeps the cases where the pattern was claimed and turned out to be false, because a collection of only confirming cases is not evidence. It is a mood.
