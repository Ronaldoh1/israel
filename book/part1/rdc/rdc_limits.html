What the Code Does Not Claim

The code in this appendix is a vocabulary, not a finding. It does not claim that the institutions on the road to 1948 were literally software, that a hidden program ran beneath them, or that the people in them coordinated in secret. Each step it names was public: Herzl published his title, the Basel programme and the Balfour letter were printed, the Mandate's articles were law, the transfer agreement was signed and reported, and the lines of 1947 and 1949 were drawn on published maps. [cite:herzl_judenstaat_1896] [cite:balfour_letter] [cite:rs_md_avalon] [cite:wiki_haavara_agreement]

Nor does it describe anyone's intentions. A technique that fits what an institution did says nothing about what a person in it believed or meant, and nothing here is about Jews as a people: the subjects are named institutions, named documents and named decisions. The code is useful because it puts a name to a shape, a commitment installed before the affected could object, a label kept while the program changed, one body forwarding for another, one gateway for the money, a line inherited and never redrawn. The same shapes can be looked for in any other record. Where the code and the record disagree, the record wins.
