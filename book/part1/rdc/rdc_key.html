How to Read the Code

Each section takes one technique from the Objective-C runtime, shows it at work on one documented part of the road, and translates it back. Five techniques are used, one per mechanism, and the last code section runs them together as one program.

Two rules hold throughout. The metaphor illuminates and never replaces: where the code and the record differ, the record wins. And the code describes structures, not intentions: a technique that fits what an institution did says nothing about what anyone privately meant.
