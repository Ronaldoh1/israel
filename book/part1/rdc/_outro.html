Read as code, the road to 1948 has a recognisable shape. The program was installed before the people it concerned were asked; its public label stayed a "home" while its implementation became a state; one recognised agency stood between the empire and the movement; the money ran through one bank; and each new line on the map inherited the last without redrawing it. [cite:zionism_founding_1897] [cite:balfour_letter] [cite:rs_md_avalon]

None of that is hidden code or a secret plan. Each step is in a published document, and each is dated and sourced in the stages of this volume. The code is a lens on what the record shows, and the network map is where it can be tested.
